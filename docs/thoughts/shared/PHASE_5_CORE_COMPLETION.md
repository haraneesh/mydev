## Architecture

### Data Flow

```
User Input
   ↓
LoginScreen (phone input)
   ↓
AuthProvider.requestOTP()
   ↓
AuthService.requestOTP()
   ↓
Meteor.call('auth.requestOTP')
   ↓
[OTP sent, navigate to OTPVerificationScreen]
   ↓
OTPVerificationScreen (6-digit OTP)
   ↓
AuthProvider.verifyOTP()
   ↓
AuthService.verifyOTP()
   ↓
Meteor.call('auth.verifyOTP')
   ↓
[Token received, stored securely]
   ↓
AuthProvider.currentUser updated
   ↓
App restores home/profile screen
```

### Component Hierarchy

```
MyApp
├── AuthProvider
│   ├── authState: AuthState
│   ├── currentUser: User?
│   └── error: String?
├── CartProvider (existing)
└── SuvaiHome → HomeScreen
    ├── LoginScreen
    ├── OTPVerificationScreen
    └── UserProfileScreen
```

### State Transitions

```
initial → authenticating → authenticated
             ↓
             → error → authenticating (retry)
             
authenticated → unauthenticated (logout)
```

## How to Use

### Start Authentication Flow
```dart
// In LoginScreen
final authProvider = context.read<AuthProvider>();
await authProvider.requestOTP(phoneNumber);
```

### Verify OTP
```dart
// In OTPVerificationScreen
final authProvider = context.read<AuthProvider>();
await authProvider.verifyOTP(phoneNumber, otp);
```

### Get Current User
```dart
// Anywhere
final authProvider = context.read<AuthProvider>();
User? user = authProvider.currentUser;
bool isAuth = authProvider.isAuthenticated;
```

### Restore Auth on App Restart
```dart
// In main.dart (already done)
ChangeNotifierProvider(
  create: (_) => AuthProvider(authService: authService)..restoreAuthState(),
),
```
