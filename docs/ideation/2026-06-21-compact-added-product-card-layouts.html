Core behavior

Adding a product changes one compact card state. It does not expose every size unless the shopper taps Edit quantity.

Why it is calmer

The selected product remains the same height as nearby cards, so the grid does not feel like it jumps after success.

Implementation fit

This can live inside the existing `AddToCart` branch: compact selected state first, quantity selector as an explicit edit state.
