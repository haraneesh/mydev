What changes from today

Search moves from a card inside the product list to the first ordering decision. Categories become fallback and discovery, not the first wall of choices.

Why this helps older users

The screen uses larger targets, clearer labels, short choices, forgiving spelling recovery, and explicit cart feedback.

Implementation boundary

This is an experience sketch, not a plan. It can be refined into requirements with one chosen layout direction.
