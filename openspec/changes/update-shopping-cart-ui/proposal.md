# Change: Update Shopping Cart UI Layout and Functionality

## Why
Improve the Shopping Cart page layout to be more compact and add product edit capability directly from the cart view, enhancing the user experience with better spacing and quick-access editing.

## What Changes
- Reduce vertical spacing between product rows in the Shopping Cart
- Add an "Edit" button below the price for quick access to modify product quantities/units
- Fix product image display to show the entire image without cropping the sides

## Impact
- Affected specs: shopping-cart
- Affected code: `mobile/lib/screens/public/cart_screen.dart`
